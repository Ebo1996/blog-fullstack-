STEP 2: DEPLOY FRONTEND TO VERCEL (10 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

☐ 1. Import project on Vercel
☐ 2. Configure:
     Framework: Next.js
     Root Directory: frontend
     
☐ 3. Add environment variables:
     NEXT_PUBLIC_API_URL=https://[YOUR-RENDER-URL].onrender.com/api
     NEXT_PUBLIC_APP_URL=https://[YOUR-VERCEL-URL].vercel.app

☐ 4. Deploy → Wait for completion

☐ 5. Copy Vercel frontend URL:
     https://________________________________.vercel.app

☐ 6. Test: Visit URL, should see homepage


STEP 3: CONNECT FRONTEND & BACKEND (5 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

☐ 1. Update Render environment variables:
     Go to: Render Dashboard → eventify-backend → Environment
     
     Update these 3 variables:
     ☐ FRONTEND_URL=[YOUR-VERCEL-URL]
     ☐ CORS_ORIGIN=[YOUR-VERCEL-URL]
     ☐ CHAPA_RETURN_URL=[YOUR-VERCEL-URL]/payment/success

☐ 2. Save (Render will auto-redeploy, wait 2-3 min)

☐ 3. Update Chapa webhook:
     URL: https://[YOUR-RENDER-URL].onrender.com/api/payments/chapa/webhook

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: Backend takes 30-60 seconds to respond
→ Normal! Render free tier has cold starts
→ Upgrade to Starter ($7/mo) for always-on

Issue: CORS errors in browser
→ Check CORS_ORIGIN in Render matches Vercel URL exactly

Issue: MongoDB connection failed
→ MongoDB Atlas → Network Access → Add 0.0.0.0/0

Issue: Build failed
→ Check logs in Render/Vercel dashboard
→ Verify environment variables are correct
